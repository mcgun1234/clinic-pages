개인정보처리방침

클리닉 영상 올리기 · 시행일 2026년 10월 23일

이 방침은 ‘클리닉 영상 올리기’(이하 ‘이 도구’)가 Google 계정과 YouTube에서 받는 정보를 어떻게 다루는지 설명합니다. 이 도구는 YouTube API 서비스를 사용합니다. Google이 정보를 다루는 방식은 Google 개인정보처리방침을 따릅니다.

1. 이 도구를 쓰는 사람

클리닉 채널을 관리하는 선생님만 이 도구에 Google 계정으로 로그인합니다. 학생, 학부모 등 다른 사람의 Google 계정 정보는 받지 않습니다. 이 방침에 동의해야 이 도구를 쓸 수 있습니다.

2. 받는 정보

선생님이 허용한 권한(YouTube 계정 관리) 안에서 다음 정보만 다룹니다.

  • 채널 이름과 채널 ID: 올바른 채널에 연결됐는지 확인하는 데 씁니다.
  • 채널의 최근 영상 목록: 이 도구의 기록과 맞춰 보는 데 씁니다.
  • 이 도구가 올린 영상의 ID, 제목, 설명, 공개 범위, 처리 상태
  • 이 도구가 넣은 자막, 재생목록, 썸네일
  • 영상의 댓글 사용 여부: 댓글이 꺼져 있는지 확인만 하고, 댓글 내용은 저장하지 않습니다.
  • YouTube API 사용량

3. 저장하는 정보와 보관 기간

  • 새로고침 토큰: 운영자가 관리하는 클라우드 작업 환경의 비밀 저장소에만 보관합니다. 화면, 파일, 작업 기록에는 남기지 않습니다.
  • 액세스 토큰: 작업하는 동안 메모리에서만 쓰고 저장하지 않습니다.
  • 올린 기록: 영상 ID, 영상 종류, 올린 때와 확인한 때, 쓴 API 사용량을 운영자의 비공개 저장소에 기록합니다. 학생은 이름 대신 번호(예: S01)로만 적고, 영상 제목·설명·자막에 학생의 이름이나 학교가 있으면 올리지 않고 멈춥니다.
  • 보관 기간: 영상을 관리하는 동안 보관하고, 아래 6에 따라 지웁니다.

4. 쓰는 곳

받은 정보는 클리닉 채널에 영상을 올리고 관리하는 데에만 씁니다. 광고, 판매, 다른 서비스에는 쓰지 않습니다. Google API에서 받은 정보의 사용과 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 다른 곳과 나누기

받은 정보를 팔거나 다른 사람에게 주지 않습니다. 영상을 만들고 올리는 작업은 운영자가 관리하는 클라우드 작업 환경에서 이루어지며, 그 밖의 곳과 나누지 않습니다. 다만 법에 따라 요구받은 경우는 예외입니다.

6. 접근 철회와 삭제

  • 이 도구의 일반적인 삭제 절차와 별도로, 언제든지 Google 보안 설정 페이지에서 이 도구의 접근 권한을 철회할 수 있습니다.
  • 접근 권한을 철회하면 운영자는 그 동의로 저장한 정보를 7일 안에, 관련된 YouTube API 데이터를 30일 안에 지웁니다.
  • 삭제를 요청하면 7일 안에 지웁니다.
