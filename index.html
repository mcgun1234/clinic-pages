클리닉 영상 올리기

수능 국어·수학 1:1 클리닉의 선생님이 수업 영상을 클리닉 유튜브 채널에 올리고 관리하는 내부 도구입니다.

하는 일

  • 학생별 주간 피드백 영상, 개념 영상, 패킷 사용법 영상을 ‘일부 공개’로 올립니다.
  • 선생님이 확인한 영상에 자막, 재생목록, 썸네일을 붙입니다.
  • 고쳐서 다시 만든 영상은 새로 올리고, 이 도구가 올렸지만 아직 확인하지 않은 옛 영상만 지웁니다.
  • 영상의 처리 상태와 댓글 설정이 맞는지 확인합니다.

쓰는 사람

클리닉 채널을 관리하는 선생님만 이 도구에 Google 계정으로 로그인합니다. 학생과 학부모는 이 도구에 로그인하지 않고, 선생님이 보낸 유튜브 링크로 영상을 봅니다. 일반에 제공하는 서비스가 아닙니다.

YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 쓰면 YouTube 서비스 약관에 동의하는 것이며, Google 개인정보처리방침이 함께 적용됩니다. 이 도구가 정보를 다루는 방식은 개인정보처리방침에, 이용 조건은 이용약관에 있습니다.
